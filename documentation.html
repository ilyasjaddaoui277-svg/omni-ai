Installation

No build process is needed. Simply:

  1. Extract the downloaded ZIP archive.
  2. Upload the omniai folder to your web server or open index.html directly in a browser.
  3. The Inter font loads via Google Fonts; all Tailwind utilities are pre-compiled to assets/css/tw-compiled.min.css — no build step, no framework CDN, works fully offline.

Production tip

For maximum performance in production, compile Tailwind with the official CLI and self-host the fonts — this removes all CDN dependencies and improves Core Web Vitals.

Colors & theme

OmniAI uses a permanent dark theme. Every color is defined as a CSS custom property at the top of style.css:

:root {
  --bg:            #090a0f;  /* Page background      */
  --bg-soft:       #0d0f17;  /* Elevated surfaces    */
  --panel:         rgba(255,255,255,0.04); /* Glass fill  */
  --border:        rgba(255,255,255,0.08); /* Glass border*/
  --indigo:        #6366f1;  /* Primary accent       */
  --violet:        #8b5cf6;  /* Secondary accent     */
  --purple:        #a855f7;  /* Tertiary accent      */
  --text:          #e7e9f2;  /* Primary text         */
  --muted:         #9aa0b4;  /* Secondary text       */
}

To rebrand the template, change these nine variables — every component updates automatically. The Tailwind config in each page maps ink and muted to the same palette.

Interactive components (JS hooks)

Attach these data attributes and main.js handles the rest:

// Tabs
<button data-tab-btn="models">…</button>
<div data-tab-panel="models">…</div>

// Accordion
<div data-accordion>
  <div class="acc-item">
    <button class="acc-btn">Question</button>
    <div class="acc-body"><div class="acc-body-inner">Answer</div></div>
  </div>
</div>

// Pricing toggle + animated counter
<button class="switch" data-billing-switch></button>
<span data-price data-monthly="49" data-annual="39">49</span>
<span data-counter="48210">0</span>

Customization

Change the accent color

Edit --indigo, --violet and --purple in style.css. Buttons, gradients, glows, and chart bars all derive from these three variables.

Add a new page

Duplicate any existing HTML file, keep the <head> block, and replace the <main> content. All nav links, styles, and scripts will work immediately.

Replace demo content

All avatars use gradient initial circles — swap them for real images via the <img> tag. The hero mockup, charts, and tables are pure CSS/HTML and fully editable.
