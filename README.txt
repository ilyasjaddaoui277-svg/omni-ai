OMNIAI — SaaS & AI HTML5 Template
=================================
Version 1.3.1 | Permanent dark theme | Locally compiled Tailwind (ZERO CDN dependency)

PAGES (13)
  index.html            Landing page (typed hero, marquee, pricing, FAQ)
  about.html            About page (mission, values, team)
  integrations.html     Integrations grid (12 connectors)
  playground.html       AI chat playground UI (working demo chat)
  dashboard.html        Dashboard UI (sidebar, widgets, chart, activity)
  dashboard-billing.html Billing page UI
  auth-login.html / auth-signup.html
  blog.html / blog-post.html
  contact.html          Validated contact form
  404.html              Error page
  documentation.html    Buyer documentation

ASSETS
  assets/css/tw-compiled.min.css  Compiled utility CSS (production)
  assets/css/style.min.css        Theme, components & animations (production)
  assets/js/main.min.js           All interactivity (vanilla JS, zero deps)
  Non-minified source files included for easy customization.

SETUP: open index.html in a browser. No build step. Works offline.
FEATURES: typing effect, marquee, tabs, accordions, pricing toggle,
form validation + toasts, animated counters & charts, back-to-top,
Open Graph + JSON-LD, sitemap.xml + robots.txt, semantic HTML5 + ARIA.

BROWSER SUPPORT (tested)
  Chrome 90+   · Edge 90+   · Opera 76+
  Firefox 88+  · Safari 14.1+ (desktop & iOS)
  Includes: vendor prefixes, Firefox scrollbar styling,
  iOS fixes (tap highlight, input zoom, 100vh), ES5-safe JS.

CREDITS
  Font: Inter (Google Fonts, SIL OFL)
  Icons: inline SVG (free for commercial use)
  Framework: Tailwind CSS utilities (pre-compiled locally, MIT)
